# Financial Markets

Веб-приложение для анализа и визуализации биржевых данных. Проект загружает исторические свечи через [Tinkoff Invest API](https://developer.tbank.ru/invest/intro/intro), рассчитывает индикатор **Ichimoku Cloud** и отображает интерактивный график в браузере.

## О проекте

Financial Markets объединяет REST API на FastAPI и простой веб-интерфейс. Пользователь выбирает актив, таймфрейм и период в днях — сервер запрашивает свечи у брокера, считает линии и облако Ichimoku и возвращает данные для построения графика.

Архитектура разделена на слои:

| Слой | Назначение |
|------|------------|
| `controllers/` | HTTP-маршруты: REST API и отдача HTML-страниц |
| `services/` | Бизнес-логика: сборка данных графика, расчёт индикаторов |
| `repositories/` | Интеграция с внешним API (Tinkoff Invest) |
| `models/` | Сущности (`CandleData`, `IchimokuData`) и Pydantic-схемы запросов/ответов |
| `config/` | Справочники FIGI и таймфреймов, настройки окружения |
| `views/` | Шаблоны, CSS и клиентский JavaScript |

## Возможности

### Данные и инструменты

- **13 активов** — российские акции (SBER, GAZP, LKOH, ROSN и др.) и зарубежные (AAPL, IBM)
- **13 таймфреймов** — от 5 секунд до месяца (`5s`, `1m`, `5m`, `1h`, `1d`, `1w`, `1M` и др.)
- **Гибкий период** — от 1 до 3650 дней истории

### Технический анализ

- Расчёт **Ichimoku Cloud** с классическими периодами (9 / 26 / 52):
  - Tenkan-sen, Kijun-sen
  - Senkou Span A и B (облако)
  - Chikou Span
- Цветовая заливка облака: зелёная зона при бычьем тренде, красная — при медвежьем

### Веб-интерфейс

- Главная страница (`/`) — форма выбора параметров с автозагрузкой списков активов и таймфреймов
- Страница графика (`/chart`) — интерактивный candlestick-график на **Plotly** с масштабированием и легендой

### REST API

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/market-data/chart` | Свечи, линии Ichimoku и полосы облака |
| `GET` | `/market-data/assets` | Список поддерживаемых тикеров |
| `GET` | `/market-data/timeframes` | Список поддерживаемых таймфреймов |
| `GET` | `/docs` | Swagger UI (автодокументация FastAPI) |

Пример запроса:

```
GET /market-data/chart?ticker=sber&timeframe=1d&days_count=30
```

## Настройка

### 1. Токен Tinkoff Invest API

Создайте файл `.env` в корне проекта:

```env
API_TOKEN=ваш_токен_tinkoff_invest
```

Токен можно получить в [личном кабинете Tinkoff Invest](https://www.tbank.ru/invest/settings/). Без `API_TOKEN` запросы к биржевым данным завершатся ошибкой.

### 2. Установка uv

В этом проекте файл `pyproject.toml` используется в качестве основного источника информации о зависимостях.

```bash
brew install uv
```

### 3. Создание виртуального окружения и его активация

```bash
uv venv .venv
source .venv/bin/activate
```

### 4. Установка всех зависимостей

```bash
uv sync
```

Пакет `tinkoff-investments` устанавливается из официального репозитория Git
с закреплённого тега, а неработающая транзитивная зависимость `tinkoff` исключается с помощью
конфигурации `[tool.uv]` в файле `pyproject.toml`.

## Запуск

```bash
uv run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Открыть:

- http://127.0.0.1:8000 — главная страница с формой
- http://127.0.0.1:8000/docs — Swagger UI

## Стек технологий

- **Python 3.11+**, FastAPI, Uvicorn
- **NumPy**, **Pandas** — расчёт индикаторов
- **tinkoff-investments** — клиент Tinkoff Invest API
- **Plotly** (CDN) — интерактивные графики в браузере
